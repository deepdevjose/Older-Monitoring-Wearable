# CareMonitor UI previews

Synthetic in-memory profiles rendered on Galaxy S22 / Android 13 with current production views. These are interface fixtures, not patient measurements. The separate preview has no network or Bluetooth permissions and was removed after 7,273 checks. The complete campaign includes 48 captures at 100% and 200% text; source hashes and scope are in `release/ANDROID_HISTORY_UI_EVIDENCE.json`.
