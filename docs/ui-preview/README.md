# CareMonitor UI previews

Code 22 production views rendered with synthetic in-memory profiles on Galaxy S22 / Android 13. These are interface fixtures, not patient measurements. The separate preview has no network or Bluetooth permissions and was removed after 7,198 checks. This folder contains representative Today, Settings, Reading details and history views; the complete campaign includes 48 captures at 100% and 200% text. Source/capture hashes and scope are in `release/ANDROID_HISTORY_UI_EVIDENCE.json`.
