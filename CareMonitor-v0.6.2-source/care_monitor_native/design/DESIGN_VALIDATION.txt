CARE MONITOR DESIGN REFERENCES

The eight PNGs in wireframes/ and wireframes-contact-sheet.png are code-rendered design references. They are not screenshots from a running Flutter application or an Android phone.

Screens: Login, Sign Up, Overview, Sensors, MAX30102 Sensor Details, Alerts, Alert Details, Settings. The interactive preview additionally opens every individual sensor detail screen.

preview.html is a standalone interactive design preview. app-screens.fragment.html is its editable inline source. The preview contains no backend requests. All readings and alerts are simulated. The demo form discards entered credentials when navigating; credentials are not written to saved preview state.

Checks completed:
- JavaScript evaluated with lightweight DOM stubs and no runtime errors.
- Eight screen routes, all six module detail routes, and four scenarios exercised.
- No-finger and offline states hide invalid measurements.
- Alert acknowledgment updates the local session display.
- Host state restoration and dynamic icon initialization exercised.
- Saved state checked to exclude email/password input.
- No fetch, XMLHttpRequest, or WebSocket calls in the authored preview.
- Code-rendered PNGs visually inspected for spacing, text clipping, and missing glyphs; glyph issues corrected with drawn line icons.
- Demo optical raw values, sample window, temperatures, ADC values, and motion values aligned with assets/sample_sensor_data.json.

Browser limitations:
Playwright attempted a direct local-file launch of the installed Microsoft Edge. Edge exited before loading a page with a sandbox crashpad named-pipe error. No browser screenshots or browser layout test results are claimed. Narrow-screen and dark-mode styles are implemented but have not been visually verified in a running browser here.

The PNGs communicate screen layout and content. Flutter uses its own Material icons and responsive layout, so icon styling and spacing may differ. The HTML preview does not reproduce Flutter form validation or all settings controls; Flutter source is the implementation reference.

Important reading labels:
- MAX30102 heart rate and SpO2 are estimates; invalid readings are unavailable.
- GY906 object temperature is surface temperature, not core temperature.
- MPU6050 shows acceleration and gyroscope; no fall classifier is implemented.
- Microphone ADC is not decibels, and photoresistor ADC percentage is not lux.
- Buzzer GPIO 25 state is unknown; remote control is not connected.
