IndiCare / CareMonitor integration v0.8.0 - ML target and evidence audit
26 October 2026

Decision
Preserve the verified NORMAL/ABNORMAL models and integrate their classification/confidence API honestly. No defensible, approved three-class target was found in the inspected dataset, code or actual assessment brief. No model was retrained and no existing measurement was rerun for this audit. The working v0.7.4 baseline was not changed.

UNRESOLVED — THREE-CLASS TARGET DEFINITION REQUIRES HUMAN/TUTOR CONFIRMATION

1. What is uncertain: the definitions of Normal, Warning and Critical, both per vital-sign task and for any combined patient status. Binary ABNORMAL does not identify which of Warning or Critical applies.
2. Why: the supplied CSV contains four binary alert targets only. The assessment explicitly requests the three states but supplies no numerical severity boundaries or labelling method. Existing code does not establish an approved conversion.
3. Missing evidence: either the intended assessment dataset with authorised three-class labels and its data dictionary, or a versioned, approved severity mapping specifying inputs, units, exact boundaries, precedence/combination rules and missing/invalid-data handling. A model-confidence threshold is not a severity definition.
4. What the group should provide: the original three-class dataset/label source, if one exists; otherwise ask the tutor to confirm the intended Normal/Warning/Critical definitions and whether a documented synthetic educational rule mapping is acceptable. Provide the written definition and approval, with examples for all three classes. Do not merely relabel ABNORMAL, disease names, Fall Detection=Yes, or low prediction confidence as Critical.
5. What can continue: authentication, Android role views, binary classification/confidence, unavailable/error/stale states, history, storage, supported alert workflows and integration tests. Three-class rubric compliance and Critical-class evaluation remain unresolved until the target is defined.

Evidence limits
The earlier run recorded 240,000 JSON-versus-scikit-learn class/probability comparisons and six ML regression tests; those are historical stored results, not new tests in this audit. Synthetic labels have simple relationships to the inputs. Identical complete five-vital vectors are separated, but individual predictor values repeat across partitions. Patient Number is not a verified participant identity. The empirical leaf class probability can be 1.0 for pure synthetic leaves and is not calibrated medical certainty. No independent assessment hidden-test performance, real-device calibration, clinical accuracy, or robustness improvement follows from the 100% synthetic scores. Dataset original provenance and confirmation that this exact CSV is the tutor-supplied assessment dataset remain unresolved.
