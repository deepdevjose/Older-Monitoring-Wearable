Before you collect

A small checklist for useful, traceable testing.

COLLECTION GUIDE
01

Connect your device

Keep the ESP32 connected to the phone over Bluetooth, with the phone’s server upload enabled. This page displays the computer’s saved data.

02

Record the test conditions

Start a named session before testing. Note the participant code, firmware and sensor placement. Stopping a test ends its label window, not data ingestion.

03

Check quality, then export

Wait for valid optical readings. A missing or invalid reading is never treated as normal. Export paired reference measurements separately for calibration.
